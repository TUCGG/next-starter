# context

> 전역 상태 관리나 컴포넌트 간 **공통 데이터 공유가 필요한 경우** React의 Context API를 활용하여 정의

## 역할

- 컴포넌트 계층 구조를 따라 전달해야 하는 **전역 상태 공유**
- 로그인 정보, 테마, 언어 설정, 권한, 모달 상태 등 **앱 전반에서 참조되는 상태 관리**
- Redux 또는 Zustand 등 상태 관리 라이브러리 도입 전 또는 병행 시 사용

### 사용 시 유의사항

- **불필요하게 많은 context 사용은 리렌더링 비용이 커질 수 있으므로 주의**
- 상태가 많은 경우에는 상태 분리 또는 외부 상태 관리 도구 고려
